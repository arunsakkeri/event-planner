Building this site

This was a class project for ISM 6225. I picked an event planner theme and thought about what a planner needs day to day: a list of events, a quick way to change them, and a view of budgets and attendance.

I built four pages in plain HTML, CSS and JavaScript. Bootstrap handles the grid and navigation so the layout works on phones. A small script injects the same menu and footer on every page, which keeps navigation consistent. The Manage Events page mocks create, read, update and delete by saving a list of events in the browser's local storage, and the analytics page reads that same list to draw three Chart.js charts. The sample data is made up for the assignment.

The hardest part was keeping all pages in sync with one data source, so I moved the storage code into a shared file. If I extended it, I would connect it to a real database and add user accounts.
